# Project 01: Blinking LED

## Objective
The goal was to use an Arduino Uno in Tinkercad to blink an LED on and off automatically.

## Components Used
- Arduino Uno R3
- Breadboard
- Red LED
- 220Ω Resistor (for current limiting)

## Code Explanation
The `setup()` function sets Pin 13 as an OUTPUT.
The `loop()` function turns Pin 13 HIGH (5V) for 1 second, then LOW (0V) for 1 second, forever.
